## Conventions

- Add reference notes under `topics/<subject>/`. Give each Markdown note a descriptive title, document version, revision date, and a short context or status line. Keep citations and distinguish personal observations from sourced claims.
- Put reusable prompts under `prompts/`. State their intended use and preserve authority rules inside the prompt. Keep document metadata outside saved prompt blocks.
- Put material awaiting review under `to-be-read/`. Use a clear sequence when order matters, and label working names as unresolved until a decision is made.
- Record documentation changes in [CHANGELOG.md](CHANGELOG.md). Version 0.0.1 establishes the initial documentation convention for this previously unversioned library.
